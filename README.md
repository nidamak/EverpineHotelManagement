# Everpine Hotel Management

Учебный проект в рамках практики: автоматизированная система управления отелем.

## Описание
Программа предназначена для учета номеров, бронирований и регистрации пользователей. 
Реализована на C# с использованием Windows Forms и базы данных SQLite.

## Функционал
* Авторизация и регистрация пользователей.
* Управление номерным фондом отеля (добавление, редактирование, удаление номеров).
* Учет доступности номеров.
* Разграничение прав доступа (администратор, оператор).

## Технологии
* **Язык**: C# (.NET)
* **Интерфейс**: Windows Forms
* **База данных**: SQLite

## Запуск
1. Откройте файл `EverpineHotelManagement.slnx` в Visual Studio 2022.
2. В конфигурации сборки выберите платформу **x64**.
3. Нажмите `Rebuild Solution` для автоматической загрузки зависимостей NuGet.
4. Запустите проект (клавиша F5).

*Файл базы данных создается автоматически в папке с исполняемым файлом при первом запуске.*
